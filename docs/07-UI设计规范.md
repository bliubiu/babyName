## 1. 设计理念
突出中国传统特色，传递传统美学的优雅与含蓄。搭配宣纸展开动画，突显中国文化共鸣（春联、牌匾、书法）

### 1.1 核心价值观

**传统美学**
设计灵感来源于中国传统美学，以宋代美学的极简与含蓄为基调，融合现代简约设计语言。整体界面追求淡雅、温润的视觉效果，传递出深厚的文化底蕴。

**温暖友好**
起名是一件充满期待和喜悦的事情，UI设计应当传递这份美好。通过圆润的线条、柔和的色彩、亲切的文案，让用户感受到温暖和关怀。

**专业可信**
作为玄学类应用，UI需要传递专业性和可信度。清晰的层次结构、严谨的信息展示、流畅的交互体验，让用户对专业性产生信任。

### 1.2 灵感来源

本设计从以下中国传统美学元素中汲取灵感：

- **宋代汝窑瓷器**：温润如玉的青色釉面 → `jade` 色系
- **传统宣纸**：细腻柔和的米白色调 → `warm-white` 色系
- **中国画留白**：大量留白营造呼吸感
- **水墨画墨韵**：浓淡干湿的墨色层次 → `ink` / `ink-light` 色系 + `ink-bleed` / `ink-spread` 动画
- **篆刻艺术**：朱砂红的点缀运用 → `seal-red` / `crimson` 色系
- **古书装帧**：金色分割线与卷轴式布局 → `divider-gold` / `seal-badge` / `name-scroll`
- **吉祥纹样**：祥云纹（云气）、回纹（连续回环）→ `bg-xiangyun` / `border-fret-top`
- **国画颜料**：胭脂、赭石、石青、朱砂橙 → `rouge` / `ochre` / `stone-blue` / `cinnabar`

### 1.3 标志性视觉元素

| 元素 | 描述 | 用途 |
|------|------|------|
| **印章徽标** | 圆形朱红底色+白色文字，如"起"字 | 页面标题旁作为品牌标识 |
| **金色分割线** | 从中心向两侧渐变的金色细线 | 标题与内容之间的装饰分隔 |
| **咨询笺卡片** | 硬纸封质感+左下立体阴影，仿命理问询单 | 关键模块容器（首页、结果页） |
| **名帖卷轴** | 竖向书写+右向左展开动画，如传统名帖 | 桌面端名字展示卡片 |
| **红绸装饰条** | 顶部横贯的朱红细条，仿卷轴挂轴 | 页面顶部装饰 |
| **宣纸卡片** | 米白底色+细腻边框，模拟纸质质感 | 辅助信息卡片容器 |
| **墨笔输入框** | 底部边框式设计，聚焦时变朱红 | 表单输入区域 |
| **朱砂按钮** | 朱红色+方形刀刻感，仿印章效果 | 主要行动号召按钮 |

### 2.5 配色原则

- **主色占比 70%**：warm-white 系背景，ink 系文字
- **辅色占比 20%**：jade 玉色用于标签、次要信息

- **金色仅用于评分和装饰线**，不过度使用
- **避免纯黑**（#000000）文字——使用 ink (#1A1A1A) 替代

## 3. 吉祥纹样系统 (v2.1 新增)

### 3.1 祥云纹（云气纹）`bg-xiangyun`

SVG 内联的重复式祥云图案，用于全局背景暗纹：

```css
.bg-xiangyun {
  background-image: url("data:image/svg+xml,...祥云路径...");
  background-repeat: repeat;
  background-size: 160px 120px;
}
```

- **实现方式**：SVG data URI 内联在 CSS 中，零额外网络请求
- **透明度**：浅色模式 6% 灰度，深色模式 4% 白色，不影响内容的可读性
- **位置**：`layout.tsx` 中 `<body>` 上，配合 `bg-texture`（宣纸纹理基底）
- **动画**：`animate-pattern-fade` 2s 淡入，避免闪烁

### 3.2 回纹边框 `border-fret-top`

回字形连续几何图案（又称勾连纹、雷纹），用于卡片/模块顶部边框：

```css
.border-fret-top {
  border-top: 3px solid transparent;
  border-image: repeating-linear-gradient(
    90deg,
    var(--color-paper-edge, #D4C5A9) 0px 4px,
    transparent 4px 6px,
    var(--color-paper-edge, #D4C5A9) 6px 10px,
    transparent 10px 14px
  ) 1;
}
```

- **颜色**：使用 `paper-edge`（#D4C5A9），褪色纸缘色，低调不抢眼
- **高度**：3px，视觉重量轻

### 3.3 宣纸纹理基底 `bg-texture`

SVG 噪声滤镜模拟宣纸纤维质感：

```css
.bg-texture {
  background-image: url("...feTurbulence 噪声...");
  opacity: 0.035;
  mix-blend-mode: multiply;    /* 浅色模式 */
}
.dark .bg-texture {
  opacity: 0.05;
  mix-blend-mode: screen;      /* 深色模式 */
}
```

- 与 `bg-xiangyun` 叠加使用
- `mix-blend-mode` 随主题切换

### 3.4 墨色晕染背景 `ink-wash-bg`

右下角渐变墨晕，模拟水墨画渗透效果：

```css
.ink-wash-bg::after {
  background: radial-gradient(ellipse at bottom right,
    rgba(26,26,26,0.02) 0%, transparent 70%);
}
```

- 仅用于大区块背景（如 `consultation-sheet`）

## 4. 书法效果系统 (v2.1 新增)

### 4.1 水墨笔触标题 `ink-calligraphy`

模拟毛笔着纸时墨晕扩散的动画标题：

```css
.ink-calligraphy {
  position: relative;
  display: inline-block;
  animation: inkBleed 1.5s ease-out forwards;
}
```

- 配合 `animate-ink-bleed` 关键帧（text-shadow 逐步扩散）
- 用于所有页面主标题、区块标题
- **不依赖自定义字体**——通过动画模拟墨韵

### 4.2 笔触下划线 `brush-underline`

仿毛笔拖尾效果的标题下划线：

```css
.brush-underline::after {
  background: linear-gradient(
    90deg, transparent, rgba(139,35,35,0.25), ...);
  border-radius: 50%;
  filter: blur(2px);
}
```

- 渐变朱红 (crimson) 透明到不透明再到透明
- `blur(2px)` 模拟墨迹边缘晕染
- 与 `ink-calligraphy` 组合使用

### 4.3 笔墨分割线 `brush-divider`

替代标准 `<hr>` 的书法风格分割线：

```css
.brush-divider {
  background: linear-gradient(90deg,
    transparent, var(--color-paper-edge), transparent);
}
```

## 12. 无障碍设计

### 12.1 色彩对比度

- ink (#1A1A1A) 在 warm-white (#F5F0E8) 上：对比度约 **12:1** —— 远超 AAA 标准
- ink-light (#4A4A4A) 在 warm-white 上：对比度约 **5.5:1** —— 满足 AA 标准
- crimson (#8B2323) 在白色上：对比度约 **4.8:1** —— 满足 AA 标准
- 评分颜色配合文字或图标，确保信息可识别

### 12.2 焦点管理

- 所有可交互元素可通过键盘聚焦（`tabIndex={0}` 或原生可聚焦元素）
- 焦点状态有明确的视觉指示（`focus:border-crimson`、`focus:outline-none` + 替代样式）
- 表单标签正确关联输入框（`htmlFor` / `id`）

### 12.3 屏幕阅读器支持

- 所有图标按钮提供 `aria-label` 中文描述
- 导航链接使用 `aria-current` 标记当前页
- 表单错误提示使用 `aria-describedby` 关联
- 动态内容变化有适当的 ARIA 提示
