## 1. 引言

### 1.1 项目背景

随着人们生活水平的提高，越来越多的新手父母愿意为宝宝投入更多精力和资金取一个好名字。然而，市面上专业的起名服务机构收费高昂，单次起名费用从500元到数万元不等，这对于普通家庭来说是一笔不小的开支。

宝宝起名大师应运而生，旨在为用户提供一款免费、专业、易用的在线起名工具，让每个家庭都能享受到高质量的起名服务。

### 1.2 项目目标

**核心目标：**

- 提供基于中国传统玄学的智能起名服务
- 让专业起名服务惠及普通家庭
- 打击高价起名机构的暴利行为

**具体目标：**

- 实现八字五行分析自动化
- 提供基于易经64卦的姓名卦象解读
- 生成符合生肖属相喜忌的名字推荐
- 实现100分制综合评分系统
- 支持PDF/HTML报告生成与下载

### 3.2 功能详细说明

#### F01：用户信息输入

**输入字段：**

| 字段   | 类型  | 必填 | 范围/说明       |
| ---- | --- | -- | ----------- |
| 姓氏   | 字符串 | 是  | 1-2个汉字      |
| 字辈   | 字符串 | 否  | 族谱辈分用字，如"振" |
| 性别   | 枚举  | 是  | 男 / 女       |
| 出生年份 | 整数  | 是  | 1900-2100   |
| 出生月份 | 整数  | 是  | 1-12        |
| 出生日期 | 整数  | 是  | 1-31        |
| 出生时辰 | 整数  | 是  | 0-23（24小时制） |
| 出生地点 | 字符串 | 否  | 用于八字调候参考    |

#### F02：八字五行分析

**输出内容：**

- 四柱八字（年柱、月柱、日柱、时柱）
- 五行分布（金、木、水、火、土的数量）
- 日主属性（日主天干及其五行属性）
- 日主强弱判断（身强/身弱）
- 喜用神推荐

**计算规则：**

```
天干五行：
- 甲、乙 → 木（阳木、阴木）
- 丙、丁 → 火（阳火、阴火）
- 戊、己 → 土（阳土、阴土）
- 庚、辛 → 金（阳金、阴金）
- 壬、癸 → 水（阳水、阴水）

地支藏干：
- 子藏癸水
- 丑藏己土、癸水、辛金
- ...（依此类推）

喜用神判断：
- 日主五行旺衰分析
- 缺什么补什么（调候优先）
- 用神选取（克制忌神、扶助日主）
```

#### F03：纳音五行查询

**纳音表（部分）：**

| 年份    | 纳音五行 |

#### F04：生肖属相

**输出内容：**

- 生肖名称（鼠、牛、虎、兔...）
- 本命五行
- 相合生肖
- 相冲生肖
- 喜忌字符
- 幸运数字
- 幸运颜色
- 幸运方位

#### F05：易经64卦解读

**起卦规则：**

```
上卦 = (姓名总笔画数 - 1) % 8 + 1
下卦 = (姓名总笔画数) % 8 + 1
动爻 = (姓名总笔画数) % 6 + 1
```

**输出内容：**

- 卦象名称
- 卦象符号
- 卦辞
- 象辞
- 爻辞
- 卦象解读（事业、财运、健康）

#### F06：名字生成

**生成规则：**

1. 根据性别筛选候选汉字库
2. 根据喜用神筛选五行匹配的字
3. 根据生肖喜忌过滤不宜使用的字
4. 优先选择寓意美好的汉字
5. 支持**姓+字辈+名**格式（如输入字辈"振"，输出"张振\*\*"）

**候选名字数量：** 50个候选名字

**输出字段：**

| 字段          | 类型  | 说明        |
| ----------- | --- | --------- |
| full\_name  | 字符串 | 完整姓名（含字辈） |
| surname     | 字符串 | 姓氏        |
| generation  | 字符串 | 字辈（如有）    |
| given\_name | 字符串 | 名         |
| pinyin      | 字符串 | 拼音        |
| meaning     | 字符串 | 寓意解释      |
| wuxing      | 字符串 | 五行属性      |
| strokes     | 整数  | 笔画数       |
| score       | 浮点数 | 综合评分      |

#### F07：名字筛选

```go
type ClassicalName struct {
    ID          int64    `json:"id"`

    Wuxing      string   `json:"wuxing"`       // 五行

}
```

### 6. 重名率查询

**整合内容**：

- 姓氏重名率
- 名字重名率
- 姓名组合重名率

**数据来源**：

- 国家统计局姓名统计数据
- 公开的姓名频率数据

**数据结构**：

```go
type NamePopularity struct {
    Surname     string  `json:"surname"`       // 姓氏
    GivenName   string  `json:"given_name"`     // 名字
    TotalCount  int     `json:"total_count"`   // 全国同名人数
    Rank        int     `json:"rank"`          // 排名
    Ratio       float64 `json:"ratio"`         // 占比(%)
    Level       string  `json:"level"`         // 等级：常见/较少/稀有
}

type PopularityLevel struct {
    Level    string  // 等级名称
    MinRatio float64 // 最小比例
    MaxRatio float64 // 最大比例
    Tips     string  // 建议
}
```

**等级划分**：

| 等级 | 比例           | 建议    |
| -- | ------------ | ----- |
| 极高 | >1%          | 重名风险高 |
| 较高 | 0.1%-1%      | 较常见   |
| 一般 | 0.01%-0.1%   | 正常    |
| 较低 | 0.001%-0.01% | 较少    |
| 极低 | <0.001%      | 稀有独特  |
