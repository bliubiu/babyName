## 项目目标

**核心目标：**

- 提供基于传统智慧的智能起名工具，融合诗经、楚辞、论语等经典文献与五行八字理论，生成有文化底蕴的好名字



**具体目标：**

- 提供基于易经64卦的姓名卦象解读
- 生成符合生肖属相喜忌的名字推荐
- 实现100分制综合评分系统
- 支持PDF/HTML报告生成与下载
- 经典文献 - 从诗经、楚辞、论语等典籍中寻找名字出处
- 五行八字 - 根据出生日期计算八字，分析五行平衡
- 字义解析 - 提供每个汉字的详细释义和文化内涵

#### F02：八字五行分析

五行分析详情：点击名字卡片可查看详细的五行分析，包括八字五行分布、缺失元素提示和名字五行搭配建议。

**输出内容：**

- 四柱八字（年柱、月柱、日柱、时柱）
- 五行分布（金、木、水、火、土的数量）
- 日主属性（日主天干及其五行属性）
- 日主强弱判断（身强/身弱）
- 喜用神推荐

**计算规则：**

```
天干五行：
- 甲、乙 → 木（阳木、阴木）
- 丙、丁 → 火（阳火、阴火）
- 戊、己 → 土（阳土、阴土）
- 庚、辛 → 金（阳金、阴金）
- 壬、癸 → 水（阳水、阴水）

地支藏干：
- 子藏癸水
- 丑藏己土、癸水、辛金
- ...（依此类推）

喜用神判断：
- 日主五行旺衰分析
- 缺什么补什么（调候优先）
- 用神选取（克制忌神、扶助日主）
```

#### F06：名字生成

**生成规则：**

1. 根据性别筛选候选汉字库
2. 根据喜用神筛选五行匹配的字
3. 根据生肖喜忌过滤不宜使用的字
4. 优先选择寓意美好的汉字
5. 支持**姓+字辈+名**格式（如输入字辈"振"，输出"张振\*\*"）

**候选名字数量：** 50个候选名字

**输出字段：**

| ----------- | --- | --------- |
| full\_name  | 字符串 | 完整姓名（含字辈） |

| given\_name | 字符串 | 名         |
| pinyin      | 字符串 | 拼音        |

#### F08：综合评分

评分体系以中国传统命理学为根基，融合音韵学、文字学与经典文献，对候选名字进行多维度量化评估。满分为 100 分，得分越高代表名字在玄学与人文双重维度上越优。

**评分总则：**

```
综合得分 = Σ(维度得分 × 维度权重)
```

---

**权重分布：**

```
        ◢─────────────────────◣
        │   八字匹配度  20%    │  ← 命理核心：喜用神契合度
        ├─────────────────────┤
        │   音韵评分    25%    │  ← 听觉体验：声调、谐音
        ├─────────────────────┤
        │   字义内涵    20%    │  ← 语义深度：寓意、文化
        ├─────────────────────┤
        │   纳音五行    10%    │  ← 年命关系：纳音相生相克
        ├─────────────────────┤
        │   诗词出处    10%    │  ← 文献溯源：经典出处
        ├─────────────────────┤
        │   生肖适配    10%    │  ← 生肖喜忌：偏旁、五行
        ├─────────────────────┤
        │   易经卦象     5%    │  ← 卦象吉凶：姓名卦解读
        ◥─────────────────────◤
```

---

**评分维度详解：**

**① 八字匹配度（20%）**

| 子维度 | 说明 | 分值范围 |
|--------|------|---------|
| 喜用神匹配 | 名字五行与喜用神的契合程度 | 0-40 |
| 五行补缺 | 名字对八字五行缺项的补充效果 | 0-30 |
| 用神得力 | 用神在名字中的力量强弱（位置、笔画） | 0-20 |
| 八字格局协调 | 名字是否与八字格局整体协调 | 0-10 |

**② 音韵评分（25%）**

| 子维度 | 说明 | 分值范围 |
|--------|------|---------|
| 声调搭配 | 平仄起伏、抑扬顿挫的节奏感 | 0-35 |
| 谐音检测 | 是否存在不雅谐音（自动过滤负分） | 0-30 |
| 读音流畅度 | 连读是否拗口、有无歧义读音 | 0-20 |
| 方言适配 | 主要方言区读音是否和谐 | 0-15 |

**③ 字义内涵（20%）**

| 子维度 | 说明 | 分值范围 |
|--------|------|---------|
| 字义优美度 | 汉字本义的正面程度与美感 | 0-35 |
| 文化内涵 | 是否承载儒家、道家等传统文化精神 | 0-25 |
| 寓意丰富度 | 名字可解读的寓意层次 | 0-20 |
| 时代适应性 | 古今语境下的语义是否一致、无歧义 | 0-20 |

**④ 纳音五行（10%）**

| 子维度 | 说明 | 分值范围 |
|--------|------|---------|
| 年命相生 | 名字纳音与年柱纳音是否相生 | 0-50 |
| 纳音补缺 | 纳音五行对八字五行的补充 | 0-30 |
| 纳音格局 | 名字整体纳音形成的格局高低 | 0-20 |

**⑤ 诗词出处（10%）**

| 子维度 | 说明 | 分值范围 |
|--------|------|---------|
| 出处权威性 | 出自诗经、楚辞、论语等经典 | 0-40 |
| 引用契合度 | 诗句原意与名字寓意的吻合度 | 0-30 |
| 出处知名度 | 诗句是否为广为传颂的名句 | 0-30 |

**⑥ 生肖适配（10%）**

| 子维度 | 说明 | 分值范围 |
|--------|------|---------|
| 生肖喜用偏旁 | 是否含生肖喜用偏旁部首 | 0-40 |
| 生肖五行相合 | 名字五行与生肖本命五行的关系 | 0-30 |
| 生肖三合六合 | 是否构成三合、六合格局 | 0-30 |

**⑦ 易经卦象（5%）**

| 子维度 | 说明 | 分值范围 |
|--------|------|---------|
| 卦象吉凶 | 姓名卦的吉凶等级 | 0-40 |
| 卦象与用神匹配 | 卦象五行与喜用神的关系 | 0-30 |
| 动爻解读 | 动爻爻辞与命主情况的契合度 | 0-30 |

**评分等级：**

| 等级 | 分数范围 | 说明 | 推荐力度 |
| --- | ------ | --- | ------- |
| A | 90-100 | 极佳 | ⭐ 强烈推荐 |
| B | 80-89 | 优秀 | 推荐 |
| C | 70-79 | 良好 | 可选 |
| D | 60-69 | 一般 | 谨慎 |
| E | <60 | 较差 | 不推荐 |

**评分计算流程：**

```
原始数据（八字、生肖、卦象等）
        │
        ▼
  7 个维度独立评分（各维度内部子维度加权求和）
        │
        ▼
  维度得分 × 维度权重 → 加权贡献分
        │
        ▼
  各维度加权贡献分求和 → 综合得分（0-100）
        │
        ▼
  对照评分等级 → 输出等级与推荐力度
```

### 1. 诗经楚辞起名

**数据来源**：[holynova/gushi\_namer](https://github.com/holynova/gushi_namer)

**整合内容**：

- 《诗经》名字库（约300+名字）
- 《楚辞》名字库（约200+名字）
- 《唐诗》名字库（约500+名字）
- 《宋词》名字库（约400+名字）
- 每个名字的出处、诗句、寓意

**数据结构设计**：

```go
type ClassicalName struct {
    ID          int64    `json:"id"`
    Name        string   `json:"name"`         // 名字
    Pinyin      string   `json:"pinyin"`       // 拼音
    Meaning     string   `json:"meaning"`      // 寓意
    Source      string   `json:"source"`       // 出处（如：诗经·周南·关雎）
    Sentence    string   `json:"sentence"`    // 诗句
    Dynasty     string   `json:"dynasty"`      // 朝代
    Author      string   `json:"author"`       // 作者
    Gender      string   `json:"gender"`       // 适用性别：male/female/both
    Wuxing      string   `json:"wuxing"`       // 五行
    Strokes     int      `json:"strokes"`      // 笔画
}
```

**示例数据**：

```json
{
  "name": "蓁蓁",
  "pinyin": "zhēn zhēn",
  "meaning": "如桃叶般鲜活明媚，青春活力与蓬勃的生命力",
  "source": "诗经·周南·桃夭",
  "sentence": "桃之夭夭，其叶蓁蓁",
  "dynasty": "先秦",
  "gender": "female",
  "wuxing": "木",
  "strokes": 16
}
```

### 6. 重名率查询

**整合内容**：

- 姓氏重名率
- 名字重名率
- 姓名组合重名率

**数据来源**：

- 国家统计局姓名统计数据
- 公开的姓名频率数据

**数据结构**：

```go
type NamePopularity struct {
    Surname     string  `json:"surname"`       // 姓氏
    GivenName   string  `json:"given_name"`     // 名字
    TotalCount  int     `json:"total_count"`   // 全国同名人数
    Rank        int     `json:"rank"`          // 排名
    Ratio       float64 `json:"ratio"`         // 占比(%)
    Level       string  `json:"level"`         // 等级：常见/较少/稀有
}

type PopularityLevel struct {
    Level    string  // 等级名称
    MinRatio float64 // 最小比例
    MaxRatio float64 // 最大比例
    Tips     string  // 建议
}
```

**等级划分**：

| 等级 | 比例           | 建议    |
| -- | ------------ | ----- |
| 极高 | >1%          | 重名风险高 |
| 较高 | 0.1%-1%      | 较常见   |
| 一般 | 0.01%-0.1%   | 正常    |
| 较低 | 0.001%-0.01% | 较少    |
| 极低 | <0.001%      | 稀有独特  |

### 智慧经典

- 《三命通会》 传统八字命理学的集大成之作，也是生辰八字起名的最核心典籍
- 《渊海子平》 八字命理学的奠基之作，首次系统确立了「四柱八字」（年柱、月柱、日柱、时柱）的排盘体系，明确了五行、十神与姓名的关联逻辑，是生辰八字起名的基础理论来源。
- 《五行大义》 讲解五行学说的经典，详细阐述了五行的起源、生克关系、与天干地支 / 汉字 / 卦象的对应规则，弥补了普通命理典籍中五行细节的缺失。
- 《周易》 
- 《易经》 
- 《周易译注》
- 《梅花易数》 讲解「梅花易数起卦法」，可通过姓名笔画、出生时间快速起卦，解析名字的吉凶运势，是「姓名占卜」的核心依据
- 《百家姓》 
- 《千家姓》 
- 《诗经》
- 《楚辞》
- 《唐诗宋词》
- 《起名学大全》 
- 《现代汉语词典》
- 《新华字典》
- 《中国姓名文化研究》
- 《八字起名通俗解读》
