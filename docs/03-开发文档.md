# 开发文档

## 一、项目概述

**项目名称**：宝宝起名大师（NameMaster）

**项目类型**：全栈Web应用

**技术栈**：
- 前端：Next.js 14 + React 18 + Tailwind CSS + TypeScript
- 后端：Go + Gin
- 数据库：支持 PostgreSQL / 内存存储（可选）
- 缓存：支持 Redis / 内存缓存（可选）
- 报告生成：Puppeteer
- 部署：Docker + Docker Compose

**架构模式**：DDD（领域驱动设计）

## 四、核心功能模块

### 4.1 名字生成模块

- **功能**：根据用户输入的姓氏、性别、出生日期等信息，生成符合八字命理的名字
- **实现**：`internal/domain/name/generator.go`
- **核心函数**：`GenerateNamesWithGeneration`
- **特性**：
  - 支持字辈功能
  - 支持五行筛选
  - 支持笔画范围筛选
  - 支持诗词经典筛选
  - 支持拼音首字母筛选

### 4.2 八字分析模块

- **功能**：分析用户的生辰八字，计算喜用神、五行等信息
- **实现**：`internal/domain/bazi/bazi.go`
- **核心函数**：`AnalyzeBazi`
- **特性**：
  - 四柱八字计算
  - 五行分布分析
  - 喜用神推算
  - 纳音五行计算
  - 黄历信息查询
  - 农历转换

### 4.3 易经卦象模块

- **功能**：根据名字笔画数计算易经卦象
- **实现**：`internal/domain/yijing/hexagram.go`
- **核心函数**：`GetHexagramByStrokes`
- **特性**：
  - 64卦完整数据
  - 卦辞、象辞、爻辞
  - 卦象匹配分析

### 4.4 紫微斗数模块

- **功能**：分析用户的紫微斗数命盘
- **实现**：`internal/domain/ziwei/ziwei.go`
- **核心函数**：`AnalyzeZiwei`
- **特性**：
  - 十四主星分析
  - 四化星分析
  - 命宫分析

### 4.5 生肖模块

- **功能**：根据出生年份确定生肖及喜忌
- **实现**：`internal/domain/zodiac/zodiac.go`
- **核心函数**：`GetZodiac`
- **特性**：
  - 12生肖完整信息
  - 相合相冲关系
  - 五行属性

### 4.6 缓存系统

- **功能**：缓存频繁计算的结果，提高响应速度
- **实现**：`internal/infrastructure/cache/cache.go`
- **核心函数**：`GetCache`、`Set`、`Get`
- **特性**：
  - 内存缓存
  - 支持过期时间
  - 自动清理

### 4.7 名字统计模块

- **功能**：查询名字重名率和排行榜
- **实现**：`internal/domain/namestat/namestat.go`
- **核心函数**：`GetNameStats`、`GetTopNames`
- **特性**：
  - 全国重名率
  - 省份重名率
  - 热门名字排行

## 五、数据模型

### 5.1 内存数据结构

```go
// Hanzi 汉字结构
type Hanzi struct {
    ID        int64
    Char      string
    Pinyin    string
    Meaning   string
    Wuxing    string  // 五行
    Strokes   int     // 笔画
    Radical   string  // 部首
    Gender    string  // 适用性别
}

// Name 名字结构
type Name struct {
    ID         int64
    Surname    string
    GivenName  string
    Pinyin     string
    Meaning    string
    UsageCount int
}

// Hexagram 易经卦象
type Hexagram struct {
    ID            int64
    Name          string
    Number        int     // 1-64
    Symbol        string  // 卦象符号
    GuaCi         string  // 卦辞
    XiangCi       string  // 象辞
    YaoCi         []string // 爻辞数组
    Interpretation string // 解读
}

// Nayin 纳音五行
type Nayin struct {
    ID      int64
    Ganzhi  string  // 干支
    Nayin   string  // 纳音
    Wuxing  string  // 五行
}

// Zodiac 生肖
type Zodiac struct {
    ID          int64
    Name        string
    Wuxing      string
    Compatible  []string // 相合
    Conflicting []string // 相冲
    AvoidChars  string   // 忌用
}

// History 历史记录
type History struct {
    ID             int64
    Surname        string
    Gender         string
    BirthDate      string
    BirthTime      string
    BirthLocation  string
    Results        string // JSON字符串
    CreatedAt      time.Time
}
```

## 六、开发环境搭建

### 6.1 后端环境

1. 安装Go 1.21+：https://golang.org/dl/
2. 克隆代码库
3. 进入backend目录
4. 安装依赖：`go mod tidy`

2. 进入frontend目录

## 七、API开发

### 7.1 API路由

所有API路由在 `cmd/server/main.go` 中注册：

```go
api := router.Group("/api/v1")
{
    // 名字生成
    api.POST("/names/generate", nameHandler.Generate)
    api.GET("/names/:id", nameHandler.GetByID)

    // 八字分析
    api.POST("/bazi/analyze", baziHandler.Analyze)

    // 易经卦象
    api.GET("/yijing/hexagram/:id", yijingHandler.GetHexagram)
    api.GET("/yijing/hexagram", yijingHandler.GetAllHexagrams)

    // 生肖
    api.GET("/zodiac/:animal", zodiacHandler.GetZodiac)
    api.GET("/zodiac", zodiacHandler.GetAllZodiacs)

    // 历史记录
    api.GET("/history", historyHandler.GetHistory)
    api.POST("/history", historyHandler.SaveHistory)
    api.DELETE("/history/:id", historyHandler.DeleteHistory)
    api.POST("/history/batch", historyHandler.BatchSaveHistory)

    // 收藏
    api.GET("/favorites", favoriteHandler.GetFavorites)
    api.POST("/favorites", favoriteHandler.SaveFavorite)
    api.DELETE("/favorites/:id", favoriteHandler.DeleteFavorite)
    api.GET("/favorites/check", favoriteHandler.CheckFavorite)
    api.POST("/favorites/batch", favoriteHandler.BatchSaveFavorite)
    api.DELETE("/favorites/batch", favoriteHandler.BatchDeleteFavorite)

    // 名字统计
    api.GET("/namestat/:name", nameStatHandler.GetNameStats)
    api.GET("/namestat", nameStatHandler.GetTopNames)
    api.GET("/namestat/:name/province", nameStatHandler.GetProvinceStats)

    // 报告生成
    api.POST("/report/pdf", reportHandler.GeneratePDF)
    api.POST("/report/html", reportHandler.GenerateHTML)

    // 黄历农历
    api.GET("/huangli", huangliHandler.GetHuangli)
    api.GET("/lunar", huangliHandler.GetLunarCalendar)
}
```

### 7.2 新增API接口

1. 在 `internal/application/handlers` 目录下创建新的处理器
2. 在 `cmd/server/main.go` 中注册路由
3. 在 `internal/application/services` 中实现业务逻辑

### 7.3 API测试

- 使用Postman或curl测试API接口
- 确保响应格式符合API文档规范
- 详细API文档见 [02-API接口文档.md](./02-API接口文档.md)

## 九、部署

### 9.1 后端部署

1. 构建可执行文件：`go build -o server cmd/server/main.go`
2. 配置环境变量
3. 启动服务器：`./server`

### 9.2 前端部署

1. 构建生产版本：`npm run build`
2. 部署到Vercel或其他静态网站托管服务
3. 配置域名和HTTPS

### 9.3 Docker部署

```yaml
# docker-compose.yml
version: '3.8'

services:
  backend:
    build: ./backend
    ports:
      - "8080:8080"
    environment:
      - DATABASE_URL=postgres://user:pass@db:5432/namemaster

  frontend:
    build: ./frontend
    ports:
      - "3000:3000"
    depends_on:
      - backend

  db:
    image: postgres:15
    environment:
      POSTGRES_USER: user
      POSTGRES_PASSWORD: pass
      POSTGRES_DB: namemaster
```

## 十一、故障排查

### 11.1 常见问题

| 问题 | 可能原因 | 解决方案 |
|------|---------|--------|
| 名字生成失败 | 输入参数错误 | 检查请求参数是否正确 |
| 八字分析错误 | 出生日期格式错误 | 确保出生日期有效 |
| 服务器启动失败 | 端口被占用 | 更改端口或停止占用端口的进程 |
