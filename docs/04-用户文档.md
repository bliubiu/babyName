# 用户文档

## 1. 系统介绍

宝宝起名系统是一个专业的起名工具，结合传统玄学理论和现代技术，为新生儿生成符合八字命理、易经卦象等理论的名字。

## 2. 功能特点

- **八字命理分析**：根据宝宝的出生日期和时间，分析八字、五行、喜用神等信息
- **名字生成**：基于八字分析结果，生成符合命理的名字
- **易经卦象分析**：根据名字笔画数计算易经卦象，提供卦象分析
- **紫微斗数分析**：提供紫微斗数命盘分析，为宝宝的命运提供参考
- **名字筛选**：支持按五行、笔画、寓意等条件筛选名字
- **报告生成**：生成详细的起名报告，支持PDF和HTML格式
- **历史记录**：保存起名历史，方便查看和比较
- **收藏管理**：收藏喜欢的名字，方便后续查看

## 3. 使用指南

### 3.1 基本操作流程

1. **输入基本信息**：
   - 姓氏：宝宝的姓氏
   - 性别：选择男或女
   - 出生日期：选择宝宝的出生年、月、日
   - 出生时间：选择宝宝的出生时、分
   - 出生地点：填写宝宝的出生地点（可选）

2. **高级选项**：
   - 名字长度：选择2-4字
   - 排除生僻字：勾选后只生成常用字
   - 五行匹配：选择需要匹配的五行
   - 经典来源：选择名字的来源，如诗经、楚辞等
   - 笔画范围：设置名字的笔画数范围
   - 包含诗词：是否包含诗词中的名字
   - 包含经典：是否包含经典文献中的名字
   - 寓意关键词：输入希望名字包含的寓意
   - 拼音首字母：设置名字的拼音首字母

3. **生成名字**：
   - 点击「生成名字」按钮
   - 系统会根据输入信息生成名字列表

4. **查看分析结果**：
   - 八字分析：查看宝宝的八字、五行、喜用神等信息
   - 易经卦象：查看名字对应的易经卦象
   - 紫微斗数：查看宝宝的紫微斗数命盘分析

5. **筛选和收藏**：
   - 使用筛选条件过滤名字
   - 点击「收藏」按钮收藏喜欢的名字

6. **生成报告**：
   - 点击「生成报告」按钮
   - 选择PDF或HTML格式
   - 下载或查看报告

### 3.2 详细功能说明

#### 3.2.1 八字分析

八字分析是起名的基础，系统会根据宝宝的出生日期和时间，计算：
- 八字：年、月、日、时的天干地支
- 五行：金、木、水、火、土的分布
- 喜用神：宝宝命理中需要补充的五行
- 纳音：出生年的纳音五行

#### 3.2.2 名字生成

系统会根据八字分析结果，生成符合以下条件的名字：
- 五行匹配：优先选择与喜用神匹配的字
- 寓意美好：选择具有积极寓意的字
- 音韵和谐：选择读起来朗朗上口的名字
- 笔画合理：选择笔画数适中的名字

#### 3.2.3 易经卦象分析

系统会根据名字的笔画数，计算对应的易经卦象：
- 卦象名称：如乾、坤、坎、离等
- 卦象寓意：每个卦象的含义和象征
- 匹配度：卦象与宝宝命理的匹配程度

#### 3.2.4 紫微斗数分析

紫微斗数是传统命理学的重要组成部分，系统会分析：
- 命宫：宝宝的命宫位置
- 主星：命宫中的主星
- 辅星：辅助主星的星曜
- 四化：禄、权、科、忌的分布
- 分析结果：基于紫微斗数的综合分析

#### 3.2.5 名字筛选

系统提供多种筛选条件：
- 五行：选择需要匹配的五行
- 笔画：设置笔画数范围
- 寓意：输入希望包含的寓意关键词
- 拼音：设置拼音首字母
- 来源：选择名字的来源（诗经、楚辞等）

#### 3.2.6 报告生成

系统支持生成两种格式的报告：
- PDF格式：适合打印和存档
- HTML格式：适合在线查看和分享

报告内容包括：
- 基本信息：宝宝的姓名、性别、出生日期等
- 八字分析：详细的八字命理分析
- 名字推荐：推荐的名字列表及分析
- 易经卦象：名字对应的卦象分析
- 紫微斗数：紫微斗数命盘分析

### 3.3 历史记录和收藏

- **历史记录**：系统会保存您的起名历史，方便您查看和比较不同的起名结果
- **收藏管理**：您可以收藏喜欢的名字，方便后续查看和使用

## 4. 常见问题

### 4.1 如何选择合适的出生时间？

如果您不确定宝宝的具体出生时间，可以选择一个接近的时间，系统会根据这个时间进行分析。如果完全不知道出生时间，可以选择中午12点，这是一个中性的时间点。

### 4.2 五行匹配是什么意思？

五行匹配是指名字的五行属性与宝宝八字中的喜用神相匹配。例如，如果宝宝的喜用神是「木」，系统会优先选择五行属「木」的字。

### 4.3 如何理解名字的评分？

名字的评分是基于以下因素计算的：
- 五行匹配度：与喜用神的匹配程度
- 寓意美好度：名字的寓意是否积极正面
- 音韵和谐度：名字读起来是否朗朗上口
- 笔画合理度：名字的笔画数是否适中

### 4.4 可以生成多少个名字？

系统默认生成50个名字，您可以通过筛选条件进一步缩小范围，找到最适合宝宝的名字。

### 4.5 报告生成需要多长时间？

报告生成通常需要几秒钟时间，具体取决于生成的名字数量和报告格式。

## 5. 最佳实践

### 5.1 起名建议

1. **结合命理**：参考八字分析结果，选择与喜用神匹配的名字
2. **寓意美好**：选择具有积极寓意的名字，避免负面含义
3. **音韵和谐**：选择读起来朗朗上口的名字，避免拗口
4. **笔画适中**：选择笔画数适中的名字，避免过于复杂
5. **避免重名**：可以使用系统的历史记录和收藏功能，避免与他人重名

### 5.2 名字测试

在确定最终名字前，建议：
1. 多读几遍，确保发音流畅
2. 检查名字的寓意是否符合期望
3. 考虑名字的书写难度
4. 考虑名字在不同场合的适用性
