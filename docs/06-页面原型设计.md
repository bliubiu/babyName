## 1. 页面结构总览

### 1.1 页面清单

本应用共包含6个主要页面：

| 页面 | 路径 | 说明 |
|------|------|------|
| 首页 | / | 信息输入页面 |
| 结果页 | /result | 名字推荐与详情 |
| 历史记录 | /history | 历史记录列表 |
| 收藏页 | /favorites | 收藏名字列表 |
| 对比页 | /compare | 名字对比页面 |
| 统计页 | /stat | 名字统计页面 |
| 黄历页 | /huangli | 黄历查询页面 |

### 1.2 页面跳转关系

```
┌──────────┐     提交表单      ┌──────────┐
│   首页   │ ───────────────► │  结果页  │
│   /      │                  │ /result  │
└──────────┘                  └─────┬─────┘
                                    │
         点击"重新起名"             │ 点击"查看历史"
         或"历史记录"               │ 点击"我的收藏"
                                    ▼
                              ┌──────────┐
                              │ 历史记录 │
                              │ /history │
                              └─────┬─────┘
                                    │
                                    │ 点击"我的收藏"
                                    ▼
                              ┌──────────┐
                              │  收藏页  │
                              │/favorites │
                              └──────────┘
```

> 信息架构；命理分析区实际已改为统一折叠容器 `CollapsibleSection`：
> ①「八字分析」默认展开；②「易经卦象 · 卦象详解」把本卦经文与梅花三卦详解

### 3.3 名字卡片功能

每个名字卡片包含以下功能：
- **❤️ 收藏按钮**：点击可收藏/取消收藏

- **点击展开详情**：点击名字卡片可展开详细信息

### 9.2 字体规范

见 `docs/07` §6.1 字体家族、§6.2 字号系统、§6.3 字间距与字符样式。
