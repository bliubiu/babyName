# 页面原型设计

> 项目名称：起名
> 版本：2.1
> 日期：2026年6月
> 变更说明：v2.1 原型图中的图标（原 emoji 占位）全部对应为 Icons.tsx 中的 SVG 组件，结果页新增 name-scroll 名帖竖排卷轴，空状态采用 consultation-sheet 咨询笺风格。

---

## 1. 页面结构总览

### 1.1 页面清单

本应用共包含6个主要页面：

| 页面 | 路径 | 说明 |
|------|------|------|
| 首页 | / | 信息输入页面 |
| 结果页 | /result | 名字推荐与详情 |
| 历史记录 | /history | 历史记录列表 |
| 收藏页 | /favorites | 收藏名字列表 |
| 对比页 | /compare | 名字对比页面 |
| 统计页 | /stat | 名字统计页面 |
| 黄历页 | /huangli | 黄历查询页面 |

### 1.2 页面跳转关系

```
┌──────────┐     提交表单      ┌──────────┐
│   首页   │ ───────────────► │  结果页  │
│   /      │                  │ /result  │
└──────────┘                  └─────┬─────┘
                                    │
         点击"重新起名"             │ 点击"查看历史"
         或"历史记录"               │ 点击"我的收藏"
                                    ▼
                              ┌──────────┐
                              │ 历史记录 │
                              │ /history │
                              └─────┬─────┘
                                    │
                                    │ 点击"我的收藏"
                                    ▼
                              ┌──────────┐
                              │  收藏页  │
                              │/favorites │
                              └──────────┘
```

### 2.3 表单字段说明

| 字段 | 控件类型 | 验证规则 | 默认值 |
|------|---------|---------|--------|
| 姓氏 | 文本输入 | 1-4个汉字，必填，仅中文 | 空 |
| 性别 | 单选按钮 | 必填 | 男 |
| 出生日期 | 弹窗选择器 | 必填，支持公历/农历切换 | 当前日期 |
| 名字类型 | 单选按钮 | 必填 | 双字名 |
| 字辈 | 文本输入+下拉选择 | 可选 | 空 |
| 偏好选择 | 多选按钮 | 可选 | 空 |
| 个性补充 | 文本输入 | 可选 | 空 |

### 3.3 名字卡片功能

每个名字卡片包含以下功能：
- **❤️ 收藏按钮**：点击可收藏/取消收藏
- **⚖️ 对比按钮**：点击可添加到对比列表（最多4个）
- **点击展开详情**：点击名字卡片可展开详细信息

## 9. 界面设计规范

### 9.1 配色方案

详细色板参考 `docs/07-UI设计规范.md` 第2节。核心 Token 如下：

| CSS Token | 色值 | 用途 |
|-----------|------|------|
| `warm-white` | #F5F0E8 | 主背景色 |
| `warm-white-light` | #FDF8F3 | 卡片/咨询笺背景 |
| `paper` | #E8DFD0 | 辅助背景、边框 |
| `paper-edge` | #D4C5A9 | 纸缘色（分隔线、角花） |
| `ink` | #1A1A1A | 主要文字 |
| `ink-light` | #4A4A4A | 次要文字 |
| `crimson` | #8B2323 | 主要按钮、强调 |
| `seal-red` | #CC2A2A | 印章红（收藏、红绸） |
| `gold` | #BD9A5A | 评分数字、装饰（v2.1 哑光调） |
| `jade` | #3D7A6A | 导航文字、标签 |
| `rouge` | #C04040 | 胭脂（点缀,v2.1） |
| `ochre` | #9A7B4F | 赭石（大地色点缀,v2.1） |
| `stone-blue` | #5B7B9A | 石青（冷色点缀,v2.1） |
| `cinnabar` | #E85D3A | 朱砂橙（强调,v2.1） |

### 9.2 字体规范

- **标题字体**：衬线字体 (font-serif)
- **正文字体**：无衬线字体 (font-sans)
- **字号**：
  - 大标题：2xl (24px)
  - 中标题：xl (20px)
  - 正文：base (16px)
  - 小字：sm (14px)

### 9.3 间距规范

- **卡片内边距**：p-6 (24px) 桌面端，p-4 (16px) 移动端
- **卡片间距**：gap-4 (16px)
- **区块间距**：mb-6 (24px)

### 9.4 圆角规范

- **卡片圆角**：rounded-lg (8px)
- **按钮圆角**：rounded-lg (8px)
- **标签圆角**：rounded-full (完全圆角)

## 10. 交互设计

### 10.1 表单交互

- **实时验证**：输入时即时显示错误提示
- **焦点状态**：输入框获得焦点时显示红色边框
- **加载状态**：提交按钮显示加载动画
- **错误提示**：使用Toast组件显示错误信息

### 10.2 列表交互

- **点击展开**：点击名字卡片展开详情
- **多选对比**：点击对比按钮添加到对比列表
- **收藏切换**：点击收藏按钮切换收藏状态

### 10.3 导航交互

- **面包屑导航**：顶部显示返回按钮
- **快速导航**：顶部显示历史记录、收藏按钮
- **页面跳转**：点击历史记录跳转到详情页

## 11. 响应式设计

### 11.1 断点设置

| 断点 | 屏幕宽度 | 说明 |
|--------|----------|------|
| sm | 640px | 小屏幕 |
| md | 768px | 中等屏幕 |
| lg | 1024px | 大屏幕 |
| xl | 1280px | 超大屏幕 |

### 11.2 响应式规则

- **移动端**：单列布局，简化信息展示
- **平板端**：两列布局，适度展示信息
- **桌面端**：三列布局，完整展示信息

## 12. 动画效果

### 12.1 页面动画

| 名称 (Tailwind) | 用途 | 时长 |
|----------------|------|------|
| `animate-fade-in-up` | 元素从下往上淡入 | 0.5s |
| `animate-fade-in` | 简单淡入 | 0.3s |
| `animate-slide-in-left` / `animate-slide-in-right` | 侧滑入 | 0.5s |
| `animate-scale-in` | 缩放进入 | 0.3s |
| `animate-seal-press` | 印章按压特效（首页徽标） | 0.6s |
| `animate-scroll-unfurl` | 名帖卷轴展开 (v2.1) | 0.8s |
| `animate-ink-bleed` | 墨迹渗透（笔触标题）(v2.1) | 1.5s |
| `animate-ink-spread` | 墨色晕开 (v2.1) | 1.2s |
| `animate-pattern-fade` | 祥云纹路淡入 (v2.1) | 2s |

### 12.2 过渡效果

- **颜色过渡**：`transition-all duration-300` - 颜色变化平滑过渡
- **悬停上浮**：`hover-lift` (`hover:-translate-y-0.5 hover:shadow-md`)
- **按钮点击**：`active:scale-[0.97]` 或 `active:scale-95`
- **持续时间**：300ms 通用，hover 效果 200ms
