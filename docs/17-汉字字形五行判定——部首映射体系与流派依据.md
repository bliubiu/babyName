# 汉字字形五行判定——部首映射体系与流派依据

## 概述

本项目对 14814 个汉字的五行属性判定，采用 **字形（偏旁部首）法** 为主、**字义法** 为辅的策略。

判定优先级：**字义法特例表 > 字形法（部首映射） > JSON源数据兜底值**

---

## 一、流派选择依据

### 判定汉字五行的四大流派

| 流派 | 方法 | 代表性人物/著作 | 本项目采用 |
|------|------|----------------|:---------:|
| **字形法**（偏旁部首法） | 根据汉字偏旁部首的五行属性判定 | 《说文解字》部首体系、徐乐吾《子平真诠评注》 | **主方法** |
| **字义法** | 根据汉字含义归类五行 | 《五行大义》萧吉 | **辅助（特例表）** |
| 数理法（笔画五行） | 根据笔画数配河图数 | 各家分歧大，无统一标准 | ❌ |
| 音韵法（五音法） | 根据声母归五音五行的分类 | 争议最大，各派分歧严重 | ❌ |

### 为什么选择字形法为主

1. **可操作性**：部首是汉字结构最稳定的特征，同一部首的字五行属性一致，便于大规模自动化处理
2. **可验证性**：部首五行归属有《说文解字》部首分类为依据，而非主观判断
3. **覆盖面广**：209 个康熙部首覆盖了《通用规范汉字表》全部 8105 字，以及《汉语大字典》中绝大部分汉字
4. **一致性**：同一部首内的字五行相同，避免了字义法中同义不同字结论不同的问题

### 为什么排除数理法和音韵法

- **数理法**：存在河图数（1/6水 2/7火 3/8木 4/9金 5/0土）和五格剖象（1/2木 3/4火 5/6土 7/8金 9/0水）两个互不兼容的体系，且均采用日本熊崎健翁体系（本项目明确禁用）
- **音韵法**：五音（宫商角徵羽）到声母的映射各流派分歧极大，同一声母在不同流派中归属不同五行，缺乏统一标准

## 二、部首五行分类方法论

### 分类总原则

部首的五行属性由部首所代表的事物本质决定，遵循《周易·说卦传》万物类象体系：

| 五行 | 本质属性 | 《说卦传》类象 |
|------|----------|----------------|
| **木** | 生长、条达、舒展 | 巽为木，为入，为绳直，为工 |
| **火** | 光明、炎上、热烈 | 离为火，为日，为电，为中女 |
| **土** | 承载、包容、稳固 | 坤为地，为母，为釜，为吝啬 |
| **金** | 变革、肃杀、坚硬 | 兑为金，为口，为巫，为毁折 |
| **水** | 润下、流动、智慧 | 坎为水，为隐伏，为矫輮，为通 |

### 具体分类法则

#### 木部（44 部首）

**法则**：取象于植物、生长、生命力、柔软延伸

| 分类 | 部首 | 归类理由 |
|------|------|----------|
| 直接植物类 | 木、艹/艸、竹、禾、米、瓜、豆、韭、黍、麻 | 草木竹禾等植物本体 > 木 |
| 植物相关类 | 耒（农具，木制）、甘（含在口，草木滋味）、香（谷物芬芳） | 与植物生长密切相关 > 木 |
| 毛发织品类 | 髟（毛发）、毛、糸/纟（丝线）、巾（纺织品） | 丝毛等柔软生长物 > 木 |
| 装饰纹理类 | 彡（毛饰画纹）、爻（交错纹理）、黹（刺绣） | 纹理交错，取象于草木交错 > 木 |
| 色彩类 | 青/靑（草木之色）、香（谷香） | 草木之色香气 > 木 |
| 其他延伸 | 长/長（生长延伸）、鼻（呼吸，草木之气）、豕（猪，食草）、麻（麻类植物） | 与生长、草木相关 > 木 |

**代表部首**：木（木字旁）、艹（草字头）、竹（竹字头）、禾（禾木旁）、糸/纟（绞丝旁）

**部首特例说明**：
- 糸/纟：丝线虽为人工制品，但其材料取自蚕丝（自然纤维），且丝线柔软延伸如草木枝条，归木。此为本项目之选择，亦有流派主张归火（因丝线为赤色）或归金（因丝线加工需金属工具），本团队经讨论取其"取于自然、柔软延伸"之意归木。

#### 火部（34 部首）

**法则**：取象于光明、热量、能量、精神、色彩视觉

| 分类 | 部首 | 归类理由 |
|------|------|----------|
| 直接火类 | 火、灬（火底） | 火的本体 > 火 |
| 光热类 | 日、光、赤 | 太阳、光明、赤色与火同属 > 火 |
| 心类 | 心、忄（竖心旁） | 心为火脏，精神活动属火 > 火 |
| 色彩视觉类 | 色、赤、青、见/見、頁/頁（头面）、首 | 视觉、色彩、头面都为火之象 > 火 |
| 言语声音类 | 言/訁、音、欠、曰 | 言语发声，心（火）之声为言 > 火 |
| 动物精气类 | 虫（龙属？争议）、隹（短尾鸟）、鸟/鳥、羽、豸（无脚虫）、马/馬（龙属，奔跑如火）、龙/龍 | 此部分争议较大，各派归属不一 > 火 |
| 气态类 | 气、血、舌（尝味，火之窍）、示/礻（神示，祭火） | 气属火、血属火、舌为心之窍 > 火 |

**代表部首**：火、灬、日、心、忄、言/訁

**部首特例说明**：
- 心/忄：中医"心为火脏"，心神属火，《黄帝内经》"南方赤色，入通于心"——此为本项目采纳的依据。有少数流派将心归于土（中央土，心主运化），或归于木（心主生发），本项目取中医正统学说归火。
- 言/訁：言为心之声，舌为心之苗，言语出自心火，故归火。
- 隹/鸟/馬/龍：此组部首各派分歧极大。本项目取《说卦传》"离为雉"之象，鸟隹属离火；马奔跑如火焰之象；龙虽属水，但龙为南方离火之精（也有争议），此处暂归火以备后续调整。

#### 土部（62 部首）

**法则**：取象于大地、承载、容器、建筑、身体、数字

| 分类 | 部首 | 归类理由 |
|------|------|----------|
| 直接土石类 | 土、山、石、田 | 大地、山岳、石、田 > 土 |
| 玉石类 | 玉/王、瓦 | 玉出山中、瓦由土制 > 土 |
| 容器建筑类 | 皿（器皿）、缶（陶器）、宀（宝盖头）、广（广字头）、厂（厂字头）、尸（尸字头）、囗（围）、穴（洞穴）、冖（秃宝盖）、冂（同字框）、凵（山字框）、高、門/门 | 容器与建筑均由土石所建 > 土 |
| 四肢动作类 | 手/扌、又、廾、爪、足、止、身、寸、大、尢、九、巨、工 | 取象于人身活动，人立于大地 > 土 |
| 数字方位类 | 一、二、十、戊、己（天干中土）、辰（地支土）、艮（卦象山） | 数字方位类取中正、中央 > 土 |
| 其他 | 鹿（山兽）、豕（猪，穴居）、鼠（鼠，穴居）、牛（农耕）、羊（山地放牧）、犬（狗）、肉/月（肉）、骨、食/飠（食物，土养万物）、鬼（归于大地）、老（寿老）、里（里弄）、面（颜面）、首（头）、立（站立）、自（鼻，土之窍）、至（到达）、而（须，土地生长） | 各取象于土地、土中生物、土上活动 > 土 |

**代表部首**：土、山、石、田、王/玉、宀、广

**部首特例说明**：
- 玉/王：玉出山中，为"石之美者"，古人以玉为山川之精，故归土。此为字形法的最主流做法。
- 宀/广/厂/穴：房屋洞穴皆为土石所建，归土。
- 大/又/止/足/身：人体动作皆为土上活动，取"人是土生"之意归土。亦有流派将人身部首归火（心火主宰），本项目取《黄帝内经》"中央土以灌四傍"、人以土为基之意，归土。

#### 金部（39 部首）

**法则**：取象于金属、锐利、变革、声音、社会关系

| 分类 | 部首 | 归类理由 |
|------|------|----------|
| 直接金属类 | 金、钅、斤（斧斤）、刀/刂、戈（兵器）、酉（酒，金属容器蒸馏） | 金属本体或金属制品 > 金 |
| 锋利类 | 辛（凿具）、匕（刀匕）、牙（齿）、齿/齒（啮咬）、角（角兽硬物）、片（木片，尖锐） | 尖锐坚硬之物 > 金 |
| 人及社会类 | 人/亻、女、儿、士、臣、民（民即士）、父（斧形）、子（另议，有争议） | 此组争议最大，历代归属不一 > 金 |
| 口类 | 口、贝/貝（钱币）、白（锧，兵器）、卜（灼骨）、卩（符节） | 口为兑之象，兑为金；贝为货币金属 > 金 |
| 力工类 | 力、几、车/車、弓、弋、殳、攴、歹（骨裂）、匕、勹、小、寸（法度） | 工具、动作、力量 > 金 |
| 声音类 | 声、音（另议）、龠（笙管，金属簧片） | 商音属金 > 金 |

**代表部首**：金/钅、刀/刂、斤、戈、人/亻、口、贝/貝

**部首特例说明**：
- 人/亻：此部首在各派中归属极为混乱。隶归木（仁者乐山？）、归火（人为万物之灵？）、归土（人立于大地？）。本项目取《周易》兑卦为金，"兑为口舌，为巫，为少女"，卦象以口舌言语为金之发声，而"人"之社会交往的核心在于口（兑），故归金。但实际上该部首字义复杂多变，字义法特例表对其进行大量覆盖。
- 口：口为兑之象，《说卦传》"兑为口"，兑为金，故归金。
- 贝/貝：古代以贝壳为货币，后演变为金属货币，故归金。
- 女："兑为少女"之象，兑为金，故归金。
- 子：甲骨文为婴儿之形，取兑为金、少女、幼小之象归金。

#### 水部（30 部首）

**法则**：取象于水流、润泽、智慧、寒冷、流动

| 分类 | 部首 | 归类理由 |
|------|------|----------|
| 直接水类 | 水、氵、冫（冰）、雨、川、巛（川）、谷（水出山口）、泉（水） | 水、冰、雨、川流 > 水 |
| 流动类 | 辶/辵（走之底）、廴（建之旁）、彳（双人旁）、行、舛 | 运动、行走、流动 > 水 |
| 气候类 | 风/風、云（含雨水）、气（云气，水汽）、雨 | 风雨云气与水循环相关 > 水 |
| 动物类 | 鱼/魚、龟/龜、黾/黽、龙/龍（争议）、舟（船，行于水上） | 水中生物或水中行器 > 水 |
| 颜色类 | 黑（水之色，玄武之色）、玄（深远，水之色）、无/無（无形，水之象） | 黑色、无形为水之象 > 水 |
| 部属类 | 鬼（归藏，水象）、骨（骨质含水）、卤/鹵（盐卤含水）、鬯（香酒，液体） | 各有水之属性 > 水 |
| 其他 | 子（另议，金部已有，此属性分歧）、亥（地支水）、不（否定，水之分离）、文（纹理，水文之美） | 各有流派理由 > 水 |

**代表部首**：氵（三点水）、冫（两点水）、雨、辶（走之底）、鱼/魚、风/風

**部首特例说明**：
- 龙/龍：极富争议的部首。龙在水中、在天上，既有水属又有火属。本项目将龙归水（水中龙），但繁体「龍」另设一个部首归水。同时龍的简化"龙"又在火部中有映射（见火部说明），实际上同一部首在两处都有，最终取决于使用场景——原字部首分支决定。
- 鬼：归水。《说文》"鬼，人所归为鬼"，归藏之意与坎水之"隐伏"相通。死后入土为安，但鬼魂属阴，坎水亦属阴，故归水。
- 文：取"水文"之意，水波之纹理为文。甲骨文中"文"象人胸前纹身，也可归土（人），此处取"花纹"之象，水波为文。

## 三、繁体异体部首处理规则

对于同一部首的简繁体异体形式，保持五行一致：

| 简体 | 繁体 | 五行 |
|------|------|:----:|
| 马 | 馬 | 火 |
| 鸟 | 鳥 | 火 |
| 贝 | 貝 | 金 |
| 车 | 車 | 金 |
| 门 | 門 | 土 |
| 钅 | 金 | 金 |
| 纟 | 糸 | 木 |
| 讠 | 言 | 火 |
| 风 | 風 | 水 |
| 鱼 | 魚 | 水 |
| 龙 | 龍 | 火(簡)/水(繁) |

注意：繁体"龍"作为独立部首归水（水中龙），而简体"龙"作为火部映射（南方龙）。

## 四、字义法特例（覆盖表）

对于字形法无法准确判定的字（因部首归属复杂或字义与本部首五行冲突），使用字义法特例表覆盖。

### 覆盖原则

1. **只覆盖字形法判定不可靠的字**，不滥用覆盖
2. **优先覆盖取名常用字**（一级常用字中高频出现）
3. **每个特例有明确的字义依据**
4. 特例的来源包括：
   - 字形与五行本质分离（如"李"虽形为木，但实际为火姓）
   - 部首字本身含义强于其部首归属（如"月"为太阴之精，本金象而取木）

| 八 | 八 | 金 | **金** | 八本为数，取河图数8为木？但八字部首为金，保留金。注：此特例待讨论 |

> **覆盖表维护原则**：覆盖表不应无限扩大。只有当字形法确实给出明显错误的结论时，才使用覆盖表纠正。通常覆盖表控制在 100~150 字以内，仅覆盖取名常用字。

## 五、实现方案

### 代码架构

```
backend/internal/domain/hanzi/radical_wuxing.go
├── RadicalWuxingMap        map[string]string  // 209 部首 → 五行
├── CharacterWuxingOverride map[string]string  // 特例字 → 五行
├── GetWuxingByRadical(radical string) string  // 根据部首查五行
└── GetCharacterWuxing(char string) string     // 综合判断单个字符的五行
```

### 判定流程

```
GetCharacterWuxing(char)
│
├─ 查 CharacterWuxingOverride → 命中直接返回（字义法优先）
│
└─ 未命中
   │
   └─ 查 HanziData[char].Radical → GetWuxingByRadical()（字形法）
      │
      └─ 命中返回 / 未命中返回空字符串（使用JSON源数据兜底）
```

### 触发时机

1. **init()**：系统启动时自动为 `HanziData` 中 291 个硬编码基础字符标注五行
2. **LoadFromJSON()**：运行时从 `hanzi.json` 加载 14814 个字时，逐字按映射规则纠正五行
