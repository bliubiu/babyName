## 1. 设计理念

### 1.1 核心价值观

本项目的UI设计遵循以下核心理念，力求为用户带来专业、温暖、值得信赖的使用体验：

**东方美学**
设计灵感来源于中国传统美学，以宋代美学的极简与含蓄为基调，融合现代简约设计语言。整体界面追求淡雅、温润的视觉效果，传递出深厚的文化底蕴。

**温暖友好**
起名是一件充满期待和喜悦的事情，UI设计应当传递这份美好。通过圆润的线条、柔和的色彩、亲切的文案，让用户感受到温暖和关怀。

**专业可信**
作为玄学类应用，UI需要传递专业性和可信度。清晰的层次结构、严谨的信息展示、流畅的交互体验，让用户对专业性产生信任。

### 1.2 灵感来源

本设计从以下中国传统美学元素中汲取灵感：

- **宋代汝窑瓷器**：温润如玉的青色釉面
- **传统宣纸**：细腻柔和的米白色调
- **中国画留白**：大量留白营造呼吸感
- **篆刻艺术**：朱砂红的点缀运用

## 3. 字体系统

### 3.1 字体选择

本应用使用以下字体组合，确保良好的中文阅读体验：

| 用途 | 字体 | 字重 | 说明 |
|------|------|------|------|
| 标题 | Noto Serif SC（思源宋体） | Bold (700) | 传统文化韵味，庄重典雅 |
| 正文 | Noto Sans SC（思源黑体） | Regular (400) | 清晰易读，现代简洁 |
| 数据 | Noto Sans SC | Medium (500) | 数字展示清晰 |
| 辅助 | Noto Sans SC | Light (300) | 辅助说明文字 |

### 3.2 字号系统

建立统一的字号层级，确保信息层次清晰：

| 层级 | 字号 | 行高 | 用途 |
|------|------|------|------|
| 大标题 | 36px / 2.25rem | 1.4 | 页面主标题 |
| 标题一 | 28px / 1.75rem | 1.4 | 区块标题 |
| 标题二 | 22px / 1.375rem | 1.4 | 卡片标题 |
| 标题三 | 18px / 1.125rem | 1.5 | 小节标题 |
| 正文大 | 16px / 1rem | 1.6 | 主要正文内容 |
| 正文 | 14px / 0.875rem | 1.6 | 常规正文 |
| 辅助 | 12px / 0.75rem | 1.5 | 标签、提示文字 |

### 3.3 字间距与行高

- 标题字间距：0.02em（微调以提升美观度）
- 正文字间距：默认
- 标题行高：1.4（紧凑有力）
- 正文行高：1.6（舒适阅读）
- 大段正文行高：2.0（增强可读性）

## 5. 组件规范

### 5.1 按钮组件

**主要按钮（Primary Button）**
- 背景色：#8B2323（深红）
- 文字色：#FFFFFF（白色）
- 圆角：8px
- 内边距：12px 24px
- 悬停态：亮度提升10%，向下位移1px
- 禁用态：透明度50%，无位移

**次要按钮（Secondary Button）**
- 边框：2px solid #C9A962
- 文字色：#C9A962
- 背景色：透明
- 圆角：8px
- 悬停态：背景变为10%透明的金色

**文字按钮（Text Button）**
- 文字色：#4A6670
- 无边框
- 悬停态：文字变为#8B2323

### 5.2 输入框组件

**文本输入框**
- 边框：1px solid #E8DFD0
- 背景色：#FFFFFF
- 圆角：6px
- 内边距：12px 16px
- 聚焦态：边框变为#C9A962，添加微弱阴影
- 错误态：边框变为#F44336，显示错误提示

**下拉选择框**
- 样式与文本输入框一致
- 右侧添加下拉箭头图标
- 选中项高亮显示

### 5.3 卡片组件

**基础卡片**
- 背景色：#E8DFD0
- 圆角：12px
- 内边距：24px
- 阴影：0 2px 8px rgba(0, 0, 0, 0.08)
- 悬停态：阴影加深，轻微上移

**信息卡片**
- 用于展示单个信息项
- 标题 + 内容的标准结构
- 标题使用黛青色，简洁明了

### 5.4 评分展示

**评分徽章**
- 圆形设计，直径48px
- 背景色根据分数变化：
  - 90分以上：#5B8C5A（绿）
  - 70-89分：#D4A574（橙）
  - 70分以下：#E8B4B4（浅红）
- 数字使用白色，18px加粗

**评分详情**
- 进度条形式展示各维度得分
- 进度条颜色与五行对应
- 分数标注在进度条右侧

### 5.5 列表组件

**名字列表项**
- 卡片式设计
- 左侧：排名徽章（1-3名为奖牌图标）
- 中间：名字、拼音、五行标签
- 右侧：评分展示
- 点击展开详情

## 6. 交互规范

### 6.1 动画效果

**过渡时长**
- 快速交互：150ms（按钮悬停、状态切换）
- 标准动画：300ms（卡片展开、页面切换）
- 慢速动画：500ms（大型组件动画）

**动画曲线**
- 缓入缓出：ease-in-out（标准动画）
- 缓出：ease-out（元素消失）
- 缓入：ease-in（元素出现）
- 弹性：cubic-bezier(0.68, -0.55, 0.265, 1.55)（弹跳效果）

**典型动画效果**
- 页面加载：淡入 + 从下方滑入，staggered delay
- 卡片悬停：轻微上浮 + 阴影加深
- 按钮点击：轻微下沉
- 列表展开：折叠动画
- 评分数字：计数器动画

### 6.2 反馈机制

**加载状态**
- 骨架屏（Skeleton）展示占位
- 加载指示器使用柔和的旋转动画
- 避免纯白背景的loading

**成功反馈**
- 绿色对勾图标 + 简短提示文字
- 自动消失（3秒后）

**错误反馈**
- 红色感叹号图标 + 错误描述
- 显示在相关字段附近
- 提供纠错建议

**空状态**
- 友好的插图 + 引导性文案
- 提供快捷操作入口

## 7. 页面设计

### 7.1 首页设计

**页面结构**
- 顶部：简洁Logo + 历史记录入口
- 中央：主表单卡片（占据主要视觉焦点）
- 底部：简短的使用说明

**视觉重点**
- 标题使用大字号，居中展示
- 表单卡片采用柔和阴影，与背景形成层次
- 提交按钮使用深红色，形成明确的行动号召

**表单设计**
- 标签位于输入框上方
- 性别选择使用单选按钮组
- 日期选择使用年月日三联下拉
- 提交按钮宽度100%

### 7.2 结果页设计

**信息组织**
- 八字分析作为第一优先级展示
- 卦象信息作为第二优先级
- 名字列表作为主要内容

**列表设计**
- 使用卡片式列表项
- 评分采用颜色编码
- 支持点击展开详情
- 展开后显示：寓意、评分明细、解读

**响应式处理**
- 手机端：单列布局，卡片宽度100%
- 平板端：双列布局
- 桌面端：三列或四列布局

### 7.3 历史记录页设计

**列表样式**
- 时间倒序排列
- 显示：时间、姓氏、性别、候选名字预览
- 支持滑动删除（移动端）
- 支持点击查看详情

  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);

## 9. 无障碍设计

### 9.1 色彩对比度

- 文字与背景对比度至少达到4.5:1
- 大号文字（18px+）对比度至少达到3:1
- 评分颜色配合文字或图标，确保信息可识别

### 9.2 焦点管理

- 所有可交互元素可通过键盘聚焦
- 焦点状态有明确的视觉指示
- 焦点顺序符合逻辑阅读顺序

### 9.3 屏幕阅读器支持

- 所有图片提供alt属性
- 表单标签正确关联输入框
- 动态内容变化有适当的ARIA提示
