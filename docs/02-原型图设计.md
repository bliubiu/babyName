# 原型图设计

> 项目名称：宝宝起名大师
> 版本：1.0
> 日期：2024年1月

---

## 1. 页面结构总览

### 1.1 页面清单

本应用共包含3个主要页面：

| 页面 | 路径 | 说明 |
|------|------|------|
| 首页 | / | 信息输入页面 |
| 结果页 | /result | 名字推荐与详情 |
| 历史记录 | /history | 历史记录列表 |

### 1.2 页面跳转关系

```
┌──────────┐     提交表单      ┌──────────┐
│   首页   │ ───────────────► │  结果页  │
│   /      │                  │ /result  │
└──────────┘                  └─────┬─────┘
                                    │
         点击"重新起名"             │ 点击"查看历史"
         或"历史记录"               │
                                    ▼
                              ┌──────────┐
                              │ 历史记录 │
                              │ /history │
                              └──────────┘
                                    │
                                    │ 点击记录
                                    ▼
                              ┌──────────┐
                              │  结果页  │
                              └──────────┘
```

## 6. 交互流程

### 6.1 名字生成流程

```
1. 用户在首页填写表单
       │
       ▼
2. 点击"开始为宝宝起名"
       │
       ▼
3. 显示加载状态（骨架屏）
       │
       ▼
4. 后端处理请求（计算八字、生成名字等）
       │
       ▼
5. 跳转到结果页，展示分析结果
       │
       ▼
6. 自动保存到历史记录
```

### 6.2 查看历史流程

```
1. 点击"历史记录"入口
       │
       ▼
2. 加载历史记录列表
       │
       ▼
3. 用户选择查看某条记录
       │
       ▼
4. 跳转到结果页，展示历史结果
```

### 6.3 删除历史流程

```
1. 在历史记录页点击删除图标
       │
       ▼
2. 弹出确认对话框
       │
       ▼
3. 用户确认删除
       │
       ▼
4. 执行删除，刷新列表
```

## 7. 响应式适配

### 7.1 屏幕尺寸对照

| 设备 | 宽度 | 布局 |
|------|------|------|
| 手机 | < 640px | 单列，100%宽度 |
| 大手机 | 640-767px | 单列，较大内边距 |
| 平板 | 768-1023px | 单列或双列 |
| 小桌 | 1024-1279px | 双列 |
| 桌面 | ≥ 1280px | 居中，最大宽度限制 |

### 7.2 关键适配点

- **表单控件**：移动端增大触摸区域
- **卡片**：平板及以上使用多列布局
- **导航**：移动端隐藏历史记录入口，点击返回区域出现
- **字体**：根据屏幕尺寸调整字号

## 8. 动画时序

### 8.1 首页加载动画

```
0ms     - 页面开始加载
0-300ms - 标题淡入
200-500ms - 表单卡片淡入上滑
400-700ms - 按钮淡入上滑
```

### 8.2 结果页加载动画

```
0ms     - 页面开始加载
0-300ms - 八字分析卡片淡入
200-500ms - 卦象卡片淡入
400-700ms - 名字列表逐项淡入（每项50ms延迟）
```

### 8.3 页面切换动画

```
入场 - 从右侧滑入 + 淡入（300ms）
出场 - 向左侧滑出 + 淡出（200ms）
```

## 9. 错误处理

### 9.1 表单验证错误

```
姓氏为空 → 显示"请输入姓氏"
性别未选 → 显示"请选择性别"
日期无效 → 显示"日期格式不正确"
```

### 9.2 网络错误

```
请求超时 → 显示"网络超时，请稍后重试"
服务器错误 → 显示"服务繁忙，请稍后重试"
网络断开 → 显示"网络连接已断开"
```

### 9.3 空状态

```
无历史记录 → 显示友好插图 + "暂无历史记录，开始起名吧"
无推荐名字 → 显示"未找到合适的名字，请调整筛选条件"
```
