## 1. 设计原则

### 1.1 性能优化原则

基于Vercel React最佳实践，导航栏设计遵循以下原则：

| 优先级 | 优化项 | 应用规则 | 影响 |
|--------|--------|----------|------|
| CRITICAL | 代码分割 | bundle-dynamic-imports | 减少初始加载体积 |
| MEDIUM | 避免重渲染 | rerender-memo | 提升交互响应速度 |
| HIGH | 组件结构 | rerender-no-inline-components | 避免不必要的remount |
| LOW | 静态优化 | rendering-hoist-jsx | 减少JSX重复创建 |

### 1.2 用户体验原则

- **渐进式加载**：核心功能优先加载，次要功能按需加载
- **即时响应**：所有交互在100ms内响应
- **视觉反馈**：悬停、点击都有明确的视觉反馈
- **移动优先**：响应式设计，适配所有设备

## 3. 性能优化实现

### 3.1 动态导入重型组件

**应用规则：bundle-dynamic-imports**

导出功能使用html2canvas和html2pdf.js等重型库，应该动态导入：

```tsx
import dynamic from 'next/dynamic'

const NavExportButtons = dynamic(
  () => import('./NavExportButtons'),
  { 
    loading: () => <div className="animate-pulse">加载中...</div>,
    ssr: false 
  }
)
```

**优化效果：**
- 减少初始bundle ~200KB
- 只在需要时加载导出功能
- 提升首屏加载速度

### 3.2 Memoized组件

**应用规则：rerender-memo**

将导航按钮提取为独立的memoized组件：

```tsx
const NavButton = memo(function NavButton({ 
  icon, 
  label, 
  onClick, 
  isActive 
}: NavButtonProps) {
  return (
    <button
      onClick={onClick}
      className={cn(
        'text-teal hover:text-crimson transition-all duration-300',
        'px-2 py-1 rounded-md hover:bg-crimson/10 hover-lift',
        isActive && 'text-crimson bg-crimson/10'
      )}
    >
      <span className="mr-1">{icon}</span>
      <span>{label}</span>
    </button>
  )
})
```

**优化效果：**
- 避免不必要的重渲染
- 提升交互响应速度
- 减少CPU使用

### 3.3 避免内联组件

**应用规则：rerender-no-inline-components**

将按钮组件定义在组件外部，而不是内部：

```tsx
// ❌ 错误：在组件内部定义
function Navigation() {
  const BackButton = () => (
    <button onClick={() => router.push('/')}>← 返回</button>
  )
  return <BackButton />
}

// ✅ 正确：在组件外部定义
const BackButton = memo(function BackButton() {
  const router = useRouter()
  return (
    <button onClick={() => router.push('/')}>← 返回</button>
  )
})
```

**优化效果：**
- 避免每次渲染都创建新组件类型
- 保持组件状态
- 减少remount开销

### 3.4 提取静态JSX

**应用规则：rendering-hoist-jsx**

将静态的按钮配置提取到组件外部：

```tsx
// 静态配置
const NAV_BUTTONS = [
  { icon: '📜', label: '历史', path: '/history' },
  { icon: '❤️', label: '收藏', path: '/favorites' },
  { icon: '📅', label: '黄历', path: '/huangli' },
] as const

// 在组件中使用
function Navigation() {
  return (
    <div>
      {NAV_BUTTONS.map((btn) => (
        <NavButton key={btn.path} {...btn} />
      ))}
    </div>
  )
}
```

**优化效果：**
- 避免重复创建JSX
- 减少内存分配
- 提升渲染性能

## 14. 故障排查

### 14.1 导出按钮不显示

**问题：** 导出按钮没有显示

**解决：** 确保同时传入 `showExport`、`onExport` 和 `onExportPDF`

```tsx
<Navigation 
  showExport={true}
  onExport={handleExport}
  onExportPDF={handleExportPDF}
/>
```

### 14.2 移动端菜单无法打开

**问题：** 点击汉堡菜单没有反应

**解决：** 检查是否有CSS冲突，确保z-index正确

### 14.3 路由不更新

**问题：** 点击按钮后路由没有变化

**解决：** 确保在Next.js的客户端组件中使用

```tsx
'use client';

import Navigation from '@/components/NavigationOptimized';
```

## 15. 最佳实践

### 15.1 按需显示功能

只在需要的页面显示相应按钮：

```tsx
// 首页：不显示返回按钮
<Navigation showBackButton={false} />

// 结果页：显示导出按钮
<Navigation showExport={true} onExport={...} onExportPDF={...} />

// 历史记录页：不显示历史按钮
<Navigation showHistory={false} />
```

### 15.2 保持Props稳定

避免在render中创建新的函数：

```tsx
// ❌ 错误
<Navigation onExport={() => exportAsImage()} />

// ✅ 正确
const handleExport = useCallback(() => {
  exportAsImage();
}, []);

<Navigation onExport={handleExport} />
```

### 15.3 使用useCallback优化回调

```tsx
import { useCallback } from 'react';

const handleExport = useCallback(() => {
  exportAsImage();
}, []);

const handleExportPDF = useCallback(() => {
  exportAsPDF();
}, []);
```
