## 二、各功能详细方案

### 1. 诗经楚辞起名

**数据来源**：[holynova/gushi_namer](https://github.com/holynova/gushi_namer)

**整合内容**：
- 《诗经》名字库（约300+名字）
- 《楚辞》名字库（约200+名字）
- 《唐诗》名字库（约500+名字）
- 《宋词》名字库（约400+名字）
- 每个名字的出处、诗句、寓意

**数据结构设计**：
```go
type ClassicalName struct {
    ID          int64    `json:"id"`
    Name        string   `json:"name"`         // 名字
    Pinyin      string   `json:"pinyin"`       // 拼音
    Meaning     string   `json:"meaning"`      // 寓意
    Source      string   `json:"source"`       // 出处（如：诗经·周南·关雎）
    Sentence    string   `json:"sentence"`    // 诗句
    Dynasty     string   `json:"dynasty"`      // 朝代
    Author      string   `json:"author"`       // 作者
    Gender      string   `json:"gender"`       // 适用性别：male/female/both
    Wuxing      string   `json:"wuxing"`       // 五行
    Strokes     int      `json:"strokes"`      // 笔画
}
```

**示例数据**：
```json
{
  "name": "蓁蓁",
  "pinyin": "zhēn zhēn",
  "meaning": "如桃叶般鲜活明媚，青春活力与蓬勃的生命力",
  "source": "诗经·周南·桃夭",
  "sentence": "桃之夭夭，其叶蓁蓁",
  "dynasty": "先秦",
  "gender": "female",
  "wuxing": "木",
  "strokes": 16
}
```

### 3. 八字排盘增强

**数据来源**：[yuantiku/ChineseBazi](https://github.com/yuantiku/ChineseBazi)

**当前问题**：
- 当前使用简化算法，未考虑节气
- 未计算大运小运
- 喜用神判断逻辑简单

**需要增强**：
1. **节气校正**
   - 24节气时间表
   - 精确的月令分界点
   - 真正的换月时间

2. **完整排盘**
   - 胎元、命宫、身宫
   - 大运起运计算
   - 十神分析

3. **喜用神智能判断**
   - 综合五行强弱
   - 调候因素
   - 格局判断

**新增数据结构**：
```go
type BaziDetail struct {
    Bazi         Bazi          // 四柱
    Nayin        string        // 纳音
    DayMaster    string        // 日主
    DayWuxing    string        // 日主五行
    Strength     string        // 身强/身弱
    Xiyongshen  []string      // 喜用神
    Yongshen    []string      // 忌用神
    Shiti        []Shiti       // 十神
    Dayaun       []Dayaun      // 大运
    Jieqi        string        // 当月节气
    Tiyang       string        // 胎元
    Mingshen     string        // 命宫
    Shengong     string        // 身宫
}

type Shiti struct {
    GanZhi string // 干支
    Shishi string // 十神
}

type Dayaun struct {
    Age       int    // 年龄
    GanZhi    string // 干支
    Niyun     string // 纳音
}
```

### 4. 八卦卦象增强

**数据来源**：[lihongxun945/gossip](https://github.com/lihongxun945/gossip)

**当前问题**：
- 64卦数据不够完整
- 缺少爻辞详细信息
- 未实现动爻变化解析

**需要增强**：
1. **完整爻辞**
   - 每卦6个爻辞
   - 动爻变化解读
   - 变卦分析

2. **卦象匹配**
   - 名字笔画→上卦
   - 姓氏笔画→下卦
   - 总笔画→动爻
   - 变卦分析

**新增数据结构**：
```go
type HexagramDetail struct {
    ID          int         `json:"id"`
    Name        string      `json:"name"`
    Symbol      string      `json:"symbol"`
    GuaCi       string      `json:"gua_ci"`        // 卦辞
    XiangCi     string      `json:"xiang_ci"`      // 象辞

    // 动爻分析
    DongYao     int         `json:"dong_yao"`      // 动爻位置(1-6)
    BianGua     string      `json:"bian_gua"`      // 变卦名称
    BianGuaYao  string      `json:"bian_gua_yao"`  // 变卦爻辞
    
    // 事业财运解读
```

### 6. 重名率查询

**整合内容**：
- 姓氏重名率
- 名字重名率
- 姓名组合重名率

**数据来源**：
- 国家统计局姓名统计数据
- 公开的姓名频率数据

**数据结构**：
```go
type NamePopularity struct {
    Surname     string  `json:"surname"`       // 姓氏
    GivenName   string  `json:"given_name"`     // 名字
    TotalCount  int     `json:"total_count"`   // 全国同名人数
    Rank        int     `json:"rank"`          // 排名
    Ratio       float64 `json:"ratio"`         // 占比(%)
    Level       string  `json:"level"`         // 等级：常见/较少/稀有
}

type PopularityLevel struct {
    Level    string  // 等级名称
    MinRatio float64 // 最小比例
    MaxRatio float64 // 最大比例
    Tips     string  // 建议
}
```

**等级划分**：
| 等级 | 比例 | 建议 |
|------|------|------|
| 极高 | >1% | 重名风险高 |
| 较高 | 0.1%-1% | 较常见 |
| 一般 | 0.01%-0.1% | 正常 |
| 较低 | 0.001%-0.01% | 较少 |
| 极低 | <0.001% | 稀有独特 |

## 四、注意事项

1. **版权问题**：诗词内容属于公共领域，但需注意出处标注准确
2. **数据准确性**：八字计算需要精确算法，建议参考专业命理典籍
3. **性能考虑**：大量数据需优化查询性能
4. **离线运行**：所有数据内置，不依赖外部API
