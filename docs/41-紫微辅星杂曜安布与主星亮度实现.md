# 41 - 紫微辅星杂曜安布与主星亮度实现

> 日期：2026-10-31 ｜ 版本：2026.10.31.2 ｜ 范围：`backend/internal/domain/ziwei`

## 1. 背景与目标

此前实现的紫微模块仅安布左辅/右弼/文昌/文曲/禄存/擎羊/陀罗/天魁/天钺九颗辅星，
`FuXingList` 与 `SuiXingList` 中声明的其余星曜长期缺失，十四主星也无亮度档位。
本次按 TDD 补齐：

1. **辅星缺口 8 星**：火星、铃星、地空、地劫、天空、截空、旬空、天伤、天使；
2. **杂曜层（12 颗全安布）**：红鸾、天喜、天哭、天虚、孤辰、寡宿、劫煞、亡神、大耗、龙池、凤阁、天姚；
3. **14 主星亮度表**：《紫微斗数全书》派档位（庙/旺/得/利/平/不/陷）。

## 2. 口径核对与金标准

选用 **iztro 2.6.3**（SylarLong/iztro）作为实排对照基准，以样本盘对拍：

- 样本：公历 2000-08-16 巳时（hour=10 → timeIndex=5）女；
- 排盘：庚辰年七月十七，命宫**己卯**（五虎遁庚 → 戊寅起，卯位得己），
  纳音城头土 → **土五局**，命宫在卯；
- 宫序：命宫地支起，其余按地支**逆排**（命→兄弟→夫妻…）；
- 对拍结果：辅星、杂曜全部落位一致，命宫合成期望（己卯、太阴+铃星、土五局）逐项吻合。

### 派差说明

- 太阳在亥：初稿曾据早期资料记为《全书》派「不」、iztro「陷」，相差一档；经核对
  Renhuai123/ziwei-doushu **v4.0-13d** 的 `WENMO_BRIGHTNESS_QS`（2026-06-20 已订正
  「子起一、1=庙…7=陷」口径），该书派在亥即记「陷」，**与 iztro 2.6.3 已统一**，
  故本实现（v2026.10.31.2）取「陷」，不再保留历史派差。

## 3. 安布规则汇总（公式）

均以 `place(zhi索引, 星名)` 落宫：`宫序 = fixIndex(命宫支 − 宫支)`。

| 星曜 | 公式 |
| --- | --- |
| 火星/铃星 | 三合起点查表（寅午戌→2,10；申子辰→3,10；巳酉丑→1,3；亥卯未→9,10），顺数生时 |
| 地空 | `11 − 时`（亥上起子时逆数） |
| 地劫 | `11 + 时`（亥上起子时顺数） |
| 天空 | `年支 + 1` |
| 截空 | 年干组查表得（子起戌亥）顺/逆两支；**按年支阴阳择支**（本书取单星口径） |
| 旬空 | 旬首支 = `年支 − 年干 + 10`，空亡两支中取与年支阴阳性相同者（单星口径） |
| 天伤 | `命宫支 − 7`（交友宫） |
| 天使 | `命宫支 − 5`（疾厄宫） |
| 红鸾/天喜 | `卯 − 年支` 与其对宫（+6） |
| 天哭/天虚 | `午 − 年支` / `午 + 年支` |
| 孤辰/寡宿 | 三合组查表（忌红鸾；表见 `GuGuaTable`） |
| 劫煞/亡神 | 三合组查表（表见 `JieShaTable`），亡神 = 劫煞对宫 |
| 龙池/凤阁 | `辰 + 年支` / `戌 − 年支` |
| 大耗 | 年支对宫，阳支+1、阴支−1 |
| 天姚 | `丑 + (月−1)`（月系） |

> **双星派注**：常见主流排盘将截空、旬空按「正当位+副置」两星同布成对两宫；
> 本实现采用 iztro 单星口径，双星派仅在源码注释中说明，未布。

## 4. 主星亮度表

- 数据： Renhuai123/ziwei-doushu **v4.0-13d** `lib/ziwei/wenmo-data.ts` 的
  `WENMO_BRIGHTNESS_QS`（《全书》派，MIT 许可，数据核对式使用，非代码移植）；
- 值域：1=庙 2=旺 3=得 4=利 5=平 6=不 7=陷，列序**自子起一**，0=留白；
- 修正（v2026.10.31.2）：早期快照 `天府` 行曾多一尾数、被「取前 12 值」截断导致
  申/酉/戌/亥 全错；v4.0-13d 中 `天府` 恰为 12 个地支值（亥=得），本实现按上游
  原样采用，不再截断。14 主星中此前另有 `太阳` 在午/未/酉/戌/亥 5 格与上游偏差
  （旧值整体偏高一级），本版一并校正为上游值。
- 对拍：14 主星 × 样本盘亮度 14/14 命中（太阳@亥 在 v4.0-13d 已与 iztro 统一为陷，
  不再存在派差）。

## 5. 结构变更

- `ZiweiChart` 新增 `SuiXing map[string][]string`（宫名→杂曜列表）、
  `Brightness map[string]string`（主星→档位，与 `ZhuXing` 同步写入）；
- `distributeFuXing` 签名扩展 `yearZhiIndex`；新增 `distributeSuiXing`；
- `Analyze` 输出文本新增【杂曜】【主星亮度】段落；`getAllXingYao` 并入命宫杂曜；
- 下游无接口破坏：`adapters.go` 仅调 `AnalyzeZiwei`，前端 ziwei 为高层语义对象。

## 6. 测试

新增 `ziwei_aux_test.go`（81 例锚点断言，全部经 iztro 实排对拍）：

- 样本盘命宫合成（己卯/太阴/铃星/土五局）；
- 火铃四组（年支三合 × 起-S顺数）；
- 空地时序 0..11 全序列；
- 截空 6 例（阴阳择支）、旬空 5 例（年干组 × 异偶支修正）；
- 天伤天使（三例命宫：子/卯/午/亥）；
- 杂曜表驱动房拍 12 例、亮度锚点 + 盘上核对（紫微旺天机陷…）；
- `Analyze` 输出（段落缺失/【主星亮度】格式）、`getAllXingYao` 命宫杂曜合并。

顺带清理：删除未接线的 `getLuckyDirection/Color/Number`（伪玄学伪随机）、
`getCareerSuggestion/getRelationshipAdvice`、`GenderTable`。
