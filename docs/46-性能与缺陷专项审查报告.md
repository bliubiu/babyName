### 问题清单

**P1｜单次 `/generate` 全量重建 5558 字候选池（最重）**
- 证据：`backend/internal/domain/fate/engine_generate.go:35`；`backend/internal/application/services/adapters_hanzi.go:66-84`；`backend/internal/infrastructure/database/sqlite/store_hanzi_data.go:171-176,187-213`（主审已 Read 确认：conditions 为空时 `SELECT … FROM hanzi_data … LIMIT 10000`，逐行 `Scan` + `json.Unmarshal(naming_categories)` + 未预分配的 `append`）。

### 问题清单

**P1｜`GET /names/task/:id` 无会话归属校验（越权读取他人生成结果）**
- 证据：`backend/internal/application/handlers/name_async_handler.go:52-58`（主审已 Read 确认）；`backend/internal/application/services/task_service.go:117`（`Submit(req *GenerateRequest)` 不接收 sid）、`:154`（`Get(id)` 不校验 sid）。

- 影响：攻击者枚举相邻 task_id 即可越权读取他人完整生成结果（姓氏、生辰、八字、候选名），且取走后原用户再取拿不到。

**P2｜前端 PII 明文持久化到 localStorage**
- 证据：`frontend/src/lib/store.ts:76-91`、`frontend/src/lib/api.ts:144-155`。
- 触发：zustand `persist` 把 `formData`（姓氏、完整生辰、出生地、长辈姓名）明文存 `namer-storage`，并另存 bearer `nm_session_id`。

- 修复：不持久化 `formData` 敏感字段；sid 改用后端已下发的 HttpOnly `nm_sid` cookie。

**P2｜鉴权契约悬空（契约误导 + 信息暴露）**
- 证据：`handlers.go:10`；`infrastructure/middleware/middleware.go:137,159`；`cmd/server/main.go:412-423,443`。

- 说明：项目为匿名工具、无账号体系，且 SameSite=Lax + CORS 白名单缓解 CSRF，故非高危；但属于"声明了却没接线"的契约误导。
- 修复：删除悬空声明或实现鉴权；`/metrics` 加保护；清理无用 CORS 头。

**P3｜`writeServiceError` 兜底文案被硬编码覆盖**
