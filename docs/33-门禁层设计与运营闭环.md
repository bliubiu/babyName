## 一、结论

- 几乎所有线上产品都设「内容门禁/黑名单」层；生成式/推荐式产品（含起名）必须做**输出侧门禁**——
  你为自己产出的内容负责，违规成本高于仅过滤用户输入。
- 成熟范式归纳为四件套：**① 分层匹配引擎 ② 可独立发布/可回滚的版本化词表 ③ 白名单/豁免 ④ 指标与人审运营闭环**。

## 二、分层（纵深防御 + 分级，本项目已是此形态）

| 层 | 作用 | 业界做法 | 本项目对应 |
|---|---|---|---|
| L1 词元级 | 廉价高精度，前置剪枝 | 黑名单 trie 剔除 | `IsNonNamingChar`（naming_quality 2990 字，候选池阶段） |
| L2 组合/规则级 | 上下文/组合风险 | 禁用组合/正则/命名实体（机关、地名、历史人物） | `IsBadCombo`(962)/`IsHistoricalFigureCombo`/`PairBlacklist` |
| L3 语音/形近级 | 防绕过 | 拼音/繁简/全半角/leetspeak/谐音/近音/形近字归一后再匹配 | `CheckBadPinyinCombo`/`CheckAllBadHomophones`（stripTone+连读含姓氏） |
| L4 模型/风险分级 | 兜底、可解释 | 分类器打分→pass/warn/block，borderline 人审 | `AssessNameRisks`(pass/warn/fail) |
| L5 合规/法务 | 红线 | 政治/机关/宗教/品牌/时政法务词表 | ✅ 独立物料 `compliance_redline`（M2，机关单位/争议地名/负面历史人物） |

原则：**廉价检查前置收敛空间，昂贵检查后置收口**（本项目字级先剔、谐音/风险后查）。

## 四、匹配技术

- **归一化前置**：大小写/繁简/全半角/去噪/拼音去调后再匹配（`stripTone`）。
- **多模式匹配**：长词/多模式用 Aho-Corasick/DFA trie（O(n)）；本项目多为双字，`map` 足够，词表扩到词组时上 trie。
- **谐音/近音/形近**：拼音归一 + 近音/形近表。

## 五、分级处置（非二元）

- 动作集：`block(硬删) / downrank(降权) / warn(标注) / 人审 / allow`。
- 本项目 `pass/warn/fail` 已是分级；建议把 `warn` 接入复审队列闭环，`fail` 给可解释命中原因（e2e 已展示 gateHits）。

## 六、工程与运营（最难是运营，非代码）

1. **表与代码分离、独立发布**（改词不发版）——已做到（JSON 外置热载）。
2. **版本化 + 热更新 + 回滚**——`data_meta` checksum + `materials import` + 原子 swap
   （ADR-006/008/011/014；**门控以 checksum 为准**）。
3. **审计追溯**：谁/何时/为何加词；命中日志脱敏（M3 已落地）——`fate.RecordGateHit` 结构化埋点
   （`CheckBadPinyinCombo` / `AssessNameRisks` 命中点），`gateaudit.Install()` sink 落日志，
   `tools/gate_audit` 出「命中审计快照」。
4. **灰度发布**新表：小流量→观察命中/误报→全量。⬜
5. **指标闭环**：命中率、误报率、漏报率(抽样)、命中延迟、复审时长——M4 已落地「本地可算」部分
   （命中率/命中分布 + `/metrics` 端点），误报/漏报/复审时长由 `GateMetricProvider` 预留注入点，待 M6 数据源。
6. **误伤治理/申诉**：白名单豁免 + 误报监控 + 人审回流。⬜
7. **评测/回归**：每次改表跑「应命中+不命中」case + golden 回归（`naming_quality_test.go`「优质组合不误伤」即此范式）。

**务实结论**：2-3 字短文本，**开源词库 + 自建红线 curated + 分级(pass/warn) + 白名单豁免**为主，商业 API 离线兜底。

**订阅机制（接 `docs/31` §11.4 / materials.lock）**：
```
cron/CI 定期 pull 上游 → 差分(line-hash) → gate_patch → materials import 版本化合入 forbidden/gate/allowlist → 灰度
上游源 + sha256 记入 materials.lock（可审计、可回滚）
```

## 九、回流闭环（bad-case → 人审 → 沉淀回表）

**天然钩子**：收藏(favorite)是隐式正反馈（已写 `curated_names`）——**被收藏的名字大概率是好的**。

1. **触发**：命中 `warn`/`fail`；**「warn 却仍被收藏」= 误报候选（高价值）**。
2. **评审队列**：新增 `gate_review(pending)` → 人审三态 `confirmed(违规)/false_positive(误报)/border(边界)`；命中侧在 `CheckBadPinyinCombo`/`AssessNameRisks` 判定点记录 `名字+层级+命中值`（**脱敏**：名字是产物无 PII，但用户画像/note 脱敏）。
3. **沉淀回表**：`confirmed→增补 forbidden/gate`；`false_positive→进 allowlist（白名单优先于黑名单）`；`border→调阈值/权重`。写成 **append-only `gate_patch.jsonl`** → 走 ADR-008 `materials import` 版本化合入（独立发布/可回滚/可审计）。
4. **度量闭环**：命中率、误报率、漏报率(抽样)、复审时长、**回流到表时长**。

**最小落地路径**：`gate_review` 表/状态机 + 命中埋点 + 收藏触发正样本 → `gate_patch.jsonl` → 复用车载 `materials import` 合入 `forbidden/gate/allowlist`，全部版本化、灰度、可回滚。

### M1 显式 allowlist 物料（2026.10.16.3）

- **物料**：新增 `allowlist`（`allowlist.json`，`Required:false` 可选物料），落库 `allowlist(entry PK, kind)`，

- **匹配优先级**：`allow > deny` —— `IsNonNamingChar`（字级）、`IsBadCombo`、`IsHistoricalFigureCombo`（组合级）
  在判定入口先查白名单，命中即豁免；祈福组合 `IsBlessingCombo` 取「内置 `blessingCombos` ∪ 物料 blessing」并集。

- **零回归**：动态集合为空时行为与既有完全一致；`allowlist` 不计入 `materialNames()` 必需物料清单，
  不影响 `VerifyMaterialsFromDB` 的 fail-fast。
- **数据**：`backend/data/allowlist.json` 种子含 9 条祈福组合（去病/弃疾/除疾/愈病/去疾/除病/愈疾/安恙/康宁），

### M2 L5 合规红线独立物料（2026.10.16.4）

### M3 命中审计埋点（2026.10.16.5）

- **埋点原语**：新增 `fate/audit.go`——事件 `GateHit`（来源 / 层级 / 类别 / 等级 / 名字 / 命中值 / 说明）
  与 `RecordGateHit`；`GateAuditTotal` / `GateAuditCounts` / `GateAuditRecent` / `ResetGateAudit` 读取与重置，
  `SetGateAuditSink` / `SetGateAuditThrottle` 配置。
- **热路径保护**：采用「全量计数 + 详情节流」——计数始终精确累加；详情按
  (层级, 类别, 等级, 命中值) 去重，同一键在节流窗口（默认 1s）内只留一条，环形缓冲封顶 256 条。
  双名 N² 评分高频命中因此不会淹没日志，也不会拖慢生成。
- **脱敏前置**：`RecordGateHit` 入队前对 名字 / 命中值 / 说明 统一掩码——身份证（18 位）、
  邮箱、手机号 → `***`（规则顺序 身份证 → 邮箱 → 手机号，避免短模式吃掉长模式）。名字是产物，
  仍统一过掩码以防调用方误传用户输入。
- **接入点**：`CheckBadPinyinCombo`（评分链路，L3/谐音连读/fail/命中值=谐音词）、
  `AssessNameRisks`（测名体检，`defer` 汇总非通过项，层级由 `riskCategoryLayer` 归类 L0~L4）。
- **落地**：`internal/infrastructure/gateaudit.Install()` 注册 sink，把事件写成结构化日志
  （`门禁命中` + 各字段）；`cmd/server` 启动时装配。domain 不依赖 infrastructure。
- **工具**：`tools/gate_audit` 新增「D. 命中审计：门禁命中埋点快照」段，生成前 `ResetGateAudit`，
  生成后打印命中总数、分类计数与最近命中（脱敏）；`-static-only` 下提示不跑生成。
  （实测 `-count 15` 生成：命中 424 条，全部为 L3/谐音连读/fail。）
- **测试**：`fate/audit_test.go`（脱敏掩码、计数与副本、节流、sink 注册/取消、时间保留、
